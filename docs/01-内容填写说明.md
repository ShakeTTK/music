# 内容填写说明

> 你以后只编辑 `content/` 目录；`site/` 里带 `*.eno` 的文件是自动生成的，**不要手改**，下次构建会被覆盖。
>
> 所有模块都是**可选、互相独立**的：不写就用默认效果；写错只会跳过这一条并记录警告，不会让站点构建失败。

## 一、速查表

| 想改什么 | 文件位置 | 格式 |
|---|---|---|
| 发行日期 | `content/releases.txt` | `作品文件夹名 = YYYY-MM-DD` |
| 歌词 | `content/lyrics/<slug>.md` | Markdown |
| 创作说明 | `content/notes/<slug>.md` | Markdown |
| 封面描述 | `content/cover-descriptions.txt` | `作品文件夹名 = 一句话` |

| 背景图 | `content/backgrounds/dark.jpg`、`light.jpg`、`home.jpg` | 图片文件 |
| 关于 / 联系方式 / 版权 / 支持作者 | `content/pages/about.md` 等 4 个文件 | Markdown |
| 艺术家简介 | `content/artist/bio.md` | Markdown |

## 三、逐项说明

### 1. 发行日期（`content/releases.txt`）

```
Abadon = 2024-01-01
Winter Eve = 2026-05-01
```

- 必须是 `YYYY-MM-DD`，写错会跳过并记录警告。
- 没写的作品保持「无日期」，不影响其它作品。
- 加了日期后，首页/RSS 会按时间排序（原来是无日期时的字母序）。

### 2. 歌词（`content/lyrics/<slug>.md`）

```markdown
夜风穿过旧街
灯火在水里摇晃

第二段……
```

- 支持 Markdown（可以加空行分段）。
- 文件为空或只有注释时，该作品不显示歌词入口。
- 会在作品页出现一个「歌词」链接（`more` 区块）。

### 3. 创作说明（`content/notes/<slug>.md`）

```markdown
写于某个雨夜，用一台旧钢琴录的 demo。
```

- 与歌词同时存在时，两部分会合并为「歌词与创作说明」。
- 同样支持 Markdown。

### 4. 封面描述（`content/cover-descriptions.txt`）

```
Abadon = 环形骸骨拱门与熔岩裂缝的暗黑插画
```

- 用于无障碍读屏和分享卡片（og:image 的 alt）。
- 不写时自动用「《作品名》的封面图」。

### 5. 自定义封面（`content/covers/`）

- 文件名 = 作品文件夹名，例如 `Abadon.jpg`、`Winter Eve.png`。
- 放了就替换原封面；没放的作品保持原封面。
- 建议正方形、至少 1400×1400。

### 6. 背景图与首页大图（`content/backgrounds/`）

| 文件名 | 用途 |
|---|---|
| `dark.jpg` | 深色主题背景 |
| `light.jpg` | 浅色主题背景（`config.ini` 里 `theme.mode = adaptive` 时启用） |
| `home.jpg` | 首页大图（右侧介绍文字旁的那张） |

- 没有就沿用现有背景图。
- 建议宽 1920px、jpg、单张 < 1MB。

### 7. 关于类页面（`content/pages/`）

| 文件 | 会出现在 |
|---|---|
| `about.md` | 首页「关于」区域 |
| `contact.md` | 首页「关于」区域 → 联系方式 |
| `license.md` | 首页「关于」区域 → 版权与授权 |
| `support.md` | 首页「关于」区域 → 支持作者 |

- 支持 Markdown。
- 只有注释、没有正文的文件会被自动省略。

### 8. 艺术家资料（`content/artist/`）

- `bio.md`：简介（Markdown）。
- 头像：目录里放任意一张图片（png/jpg/webp），自动作为艺术家头像。
- `links.txt`：社交链接，每行一个：

```
网易云音乐 = https://music.163.com/#/user/home?id=xxxx
Bilibili = https://space.bilibili.com/xxxx
```

- 艺术家名固定为「千里」，网址是 `/qianli/`。
- 社交链接会同时出现在艺术家页、页脚和作品页。

### 9. 外链下载（`content/downloads.txt`）

```
Abadon = 网易云音乐 https://music.163.com/song?id=xxxx
Abadon = QQ音乐 https://y.qq.com/n/ryqq/songDetail/xxxx
```

- 一个作品可以写多行，点击下载按钮会弹出多个平台并**跳转**到对应链接。
- 没写的作品不显示下载按钮（保持仅在线收听）。
- 必须带 `http://` 或 `https://`。

### 10. 功能开关（`content/config.ini`）

- `[brand]`：LOGO / favicon 版本，`logo = 1/2/3`（对应 `docs/logo-proposals/` 里的三版方案）。
- `[water]`：水波效果开关、强度、透明度。
- `[comments]`：评论窗口，需要先填 `repo_id` / `category_id`（见部署文档）。
- `[analytics]`：低调统计，`enabled = true` 并配置 token 后生效，页面不会显示任何东西。
- `[embed]`：嵌入播放器开关。
- `[theme]`：`dark` / `light` / `adaptive`。

## 四、写错会怎样？

| 情况 | 结果 |
|---|---|
| 日期格式错 | 跳过该条，记录警告，其它作品正常 |
| 下载链接不是 http(s) | 跳过该条，记录警告 |
| 社交链接格式错 | 跳过该行，记录警告 |
| 封面图片损坏 | 构建时该图处理失败，Farcamp 会报错；请确保图片能正常打开 |
| 歌词文件不存在 | 该作品不显示歌词入口，正常构建 |
| `config.ini` 某个值写错 | 回退默认值（如主题回退 dark），记录警告 |

构建结束后查看 `logs/generate-report.txt`，里面有所有模块状态与警告清单。
