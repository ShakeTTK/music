# 多语言文案模块说明

> 目标：界面文字（按钮、播放器、提示语等）支持多语言，文案放在独立的 JSON 文件里，
> 新增语言只需新增文件，不需要改代码。歌曲名、歌词、简介等内容仍保持原文。

## 一、文件位置

```
content/i18n/
├─ zh.json     中文（默认语言）
└─ en.json     英文
```

每种语言一个 JSON 文件，**文件名就是语言代码**（`zh.json` → `zh`）。
构建时 `scripts/generate.py` 会自动读取所有 `*.json`，打包成站点的 `i18n.js`。

### 文件格式

```json
{
  "name": "English",
  "short": "EN",
  "html_lang": "en",
  "strings": {
    "player.button": "Playlist",
    "player.title": "Temporary Playlist"
  }
}
```

| 字段 | 说明 |
|---|---|
| `name` | 语言全名，用于切换按钮的提示 |
| `short` | 切换按钮上显示的短名称，如 `中` / `EN` |
| `html_lang` | 切换后写入 `<html lang="...">` 的值 |
| `strings` | 文案键值对；缺少的键会自动回退到中文 |

## 二、新增一种语言

1. 复制 `content/i18n/en.json` 为 `content/i18n/<代码>.json`（如 `ja.json`）
2. 修改 `name`、`short`、`html_lang`
3. 翻译 `strings` 里的值（键名保持不变）
4. 重新构建并部署

页面右上角会自动出现新的语言按钮，无需改任何脚本。

## 三、切换行为

- 首次访问：按浏览器语言（`navigator.languages`）自动选择，找不到则用中文
- 手动切换：点击标题旁的「中 / EN」按钮
- 选择会保存在 `localStorage` 的 `music-site-lang`，刷新/再次访问都保持
- 站内无刷新跳转后，切换按钮和翻译状态保持不变
- 不按 IP 自动跳转，避免误判和隐私问题

## 四、翻译范围

已接入的界面文案：

| 模块 | 键名前缀 | 说明 |
|---|---|---|
| 临时歌单 | `player.*` | 歌单按钮、标题、背景透明度、音量、全选、播放模式、清空、提示、无障碍标签 |
| 详情页音量 | `page.volume` | 收听旁边的音量标签 |
| 水波开关 | `water.*` | 水波开/关、开关提示 |
| Faircamp 自带操作 | `faircamp.*` | 浏览、收听、复制链接、嵌入、播放/暂停、音量、静音等 |

**不翻译**：歌曲名、艺术家名、歌词、创作说明、关于页、下载说明等内容，这些仍以原文展示。

## 五、开发时新增文案

1. 在 `content/i18n/zh.json` 和 `en.json` 的 `strings` 中都加上同一个键
2. 自定义模块里用 `window.SiteI18n.t('your.key', '默认文字')`
3. 静态元素也可以直接用属性：

```html
<span data-i18n="player.button">歌单</span>
<input data-i18n-aria="player.volume" aria-label="音量">
```

4. 切换语言后，`site:languagechange` 事件会触发，动态文字（如全选/取消全选、当前曲目）在事件里重新渲染

## 六、实现组成

| 文件 | 作用 |
|---|---|
| `content/i18n/*.json` | 唯一需要编辑的文案来源 |
| `scripts/generate.py`（`write_i18n_js`） | 合并语言文件，生成 `site/i18n.js` |
| `scripts/assets/i18n-runtime.js` | 语言检测、切换按钮、文案应用、Faircamp 界面翻译 |
| `scripts/assets/music-player.js` / `water.js` | 通过 `SiteI18n.t()` 和 `data-i18n` 接入翻译 |

> `site/i18n.js` 是构建产物，不要手改；改文案请改 `content/i18n/`。

## 七、限制与后续

- 目前只做界面文案，页面正文/歌词不翻译
- Faircamp 自带的浏览器弹窗等极少数动态文字可能仍为站点默认语言，可后续补充文案键
- 如果以后要做**整站内容翻译**（页面、歌词、说明都分语言），需要改为按语言生成独立站点路径，参见 `docs/04-SPA重构方案.md` 中的多语言/路由部分
