# 目录结构与模块说明

## 一、目录树

```
MyMusicCatalog.v2/
├─ content/                    ← 你日常编辑这里
│  ├─ config.ini               功能开关（公开信息）
│  ├─ releases.txt             发行日期
│  ├─ cover-descriptions.txt   封面描述
│  ├─ downloads.txt            外链下载
│  ├─ lyrics/                  歌词（<slug>.md）
│  ├─ notes/                   创作说明（<slug>.md）
│  ├─ pages/                   关于 / 联系方式 / 版权 / 支持作者
│  ├─ artist/                  艺术家简介 / 头像 / 社交链接
│  ├─ backgrounds/             背景图 / 首页大图
│  └─ covers/                  自定义封面
│
├─ site/                       ← Faircamp 站点源（29 首作品 + 图片）
│  ├─ site.eno                 （自动生成）
│  ├─ Homepage/catalog.eno     （自动生成）
│  ├─ Artist/artist.eno        （自动生成）
│  ├─ <作品目录>/track.eno      （自动生成）
│  ├─ custom.css / water.js / comments.js / analytics.js （构建时复制）
│  ├─ .faircamp_build/         构建产物（已 gitignore）
│  └─ .faircamp_cache/         构建缓存（已 gitignore）
│
├─ scripts/
│  ├─ generate.py              内容 -> 清单 的生成器（模块化、容错）
│  ├─ build_local.py           本地构建（生成 → 构建 → 后处理）
│  ├─ postprocess.py           构建后处理（目前修复订阅源链接）
│  ├─ build.bat / preview.bat  本地构建 / 预览
│  ├─ update.bat               上传脚本（构建 + 提交 + 推送）
│  └─ assets/                  前端模块源码（水波 / 评论 / 统计 / 样式 / APlayer）
│
├─ docs/                       说明文档（本目录）
├─ logs/                       生成报告（自动生成，已 gitignore）
├─ .github/workflows/deploy.yml 云端构建与发布
└─ README.md
```

## 二、构建链路

```
content/*  ──generate.py──▶  site/*.eno + 复制图片
                                   │
                                   ▼
                          faircamp build
                                   │
                                   ▼
                    site/.faircamp_build/（静态站点）
                                   │
                    postprocess.py（可选后处理）
                                   │
                                   ▼
                     GitHub Actions → GitHub Pages
```

## 三、模块清单与故障隔离

| 模块 | 负责文件 | 失败时 |
|---|---|---|
| 配置 | `content/config.ini` | 回退默认配置，记警告 |
| 发行日期 | `content/releases.txt` | 跳过无效条目，记警告 |
| 歌词 | `content/lyrics/` | 该作品不显示歌词，记警告 |
| 创作说明 | `content/notes/` | 该作品不显示说明，记警告 |
| 封面描述 | `content/cover-descriptions.txt` | 用默认描述 |
| 下载链接 | `content/downloads.txt` | 跳过无效链接，其余作品正常 |
| 关于类页面 | `content/pages/` | 该小节省略 |
| 艺术家资料 | `content/artist/` | 艺术家页仍生成，简介/头像/链接为空 |
| 背景图 | `content/backgrounds/` | 用默认背景 |
| 自定义封面 | `content/covers/` | 保留原封面 |
| 前端资源 | `scripts/assets/` | 缺失的文件对应功能自动不启用 |
| 水波效果 | `scripts/assets/water.js` + `scripts/assets/ripples/`（jquery.ripples，MIT） | WebGL 不可用时静默保留静态背景 |
| 临时歌单 | `scripts/assets/music-player.js` + `scripts/postprocess.py`（build_player_index） | 索引加载失败时播放器不显示，不影响页面 |
| 无刷新跳转 | `scripts/assets/navigation.js` | 失败自动回退整页跳转；播放器在页外常驻 |
| 评论窗口 | `scripts/assets/comments.js` | 未配置/加载失败时隐藏，不影响页面 |
| 访问统计 | `scripts/assets/analytics.js` | 未配置/被拦截时静默退出 |
| 嵌入播放器 | `scripts/postprocess.py` + `scripts/assets/aplayer/` | 失败时保留 Faircamp 原生嵌入页 |
| 后处理 | `scripts/postprocess.py` | 失败只告警，站点照常部署 |

生成器内部用「模块函数 + 统一容错包装」实现：每个模块都在独立函数中运行，异常统一捕获并写入 `logs/generate-report.txt`；只有写入 `site/site.eno` 这类核心步骤失败才返回非零退出码。

## 四、自动生成的文件（不要手改）

- `site/site.eno`
- `site/Homepage/catalog.eno`
- `site/Artist/artist.eno`
- `site/<每个作品>/track.eno`
- `site/custom.css`、`site/water.js`、`site/comments.js`、`site/analytics.js`（从 `scripts/assets/` 复制）

如果你手改了这些文件，下次构建会被覆盖。要改内容请改 `content/`，要改样式/交互请改 `scripts/assets/`。

## 五、手工维护的文件

- `site/` 下每个作品的音频与原始封面（新增作品就在这里加文件夹）
- `content/` 下全部内容
- `scripts/` 下构建与前端模块
- `.github/workflows/deploy.yml`
